# 🎮 Super-Arcade - Simulador de Tienda de Videojuegos PS2

Simulador interactivo desarrollado en JavaScript puro como parte de las prácticas y entregas del curso de programación. Este proyecto simula un sistema de control de stock y carrito de compras para una tienda retro de videojuegos de PlayStation 2.

## 📁 Estructura del Proyecto
El repositorio contiene la estructura básica de archivos para ejecutar la aplicación:
- `index.html`: Archivo HTML principal que enlaza el script mediante la etiqueta `<script src="main.js" defer></script>`.
- `main.js`: Archivo central que nuclea toda la lógica del simulador (estructuras de control, funciones, manejo de arrays y lógica de negocio).

## 🚀 Características y Tecnologías (Pre-Entrega 4)
- **Manipulación de Arrays:** Gestión dinámica de inventario utilizando métodos de extremos (`push`, `unshift`, `pop`), búsqueda y validación (`includes`, `indexOf`), y actualización de elementos por índice (`splice`).
- **Control de Flujo:** Menú interactivo dinámico gestionado mediante bucles `while` y condicionales (`if/else`).
- **Modularización:** Funciones reutilizables para el cálculo de descuentos, gestión del carrito y recorrido de colecciones mediante bucles modernos `for...of`.
- **Interacción:** Experiencia basada en `prompt`, `alert` y reportes detallados en la consola del navegador.

## 💻 ¿Cómo ejecutar el proyecto?
1. Clona este repositorio en tu computadora o descárgalo como archivo ZIP.
2. Abre el archivo `index.html` en tu navegador web preferido (Google Chrome, Firefox, etc.).
3. Abre la **Consola de Desarrollador** de tu navegador (`F12` o `Ctrl + Shift + J`) para visualizar los reportes detallados del stock y el resumen de compra en tiempo real.
